Array Destructuring

  • Destructuring Arrays: Array Destructuring is the process of unpacking(extracting) values from arrays into distinct variables.
  • Nested Destructuring: Nested Destructuring allows unpacking values from nested arrays or objects into distinct variables.
  • Destructuring with Default Values: This technique provides default values for variables when the unpacked value is undefined.

Object Destructuring

  • Destructuring Objects: Object Destructuring is the process of unpacking properties from objects into distinct variables.
  • Nested Destructuring: Nested Destructuring allows unpacking properties from nested objects into distinct variables.
  • Destructuring with Default Values: This technique provides default values for variables when the unpacked property is undefined.

Spread Operator

  • The Spread Operator (...) is used to expand elements of an iterable (like an array or string) or properties of an object into individual elements or key-value pairs.
  • Difference between spread operator vs Destructuring: Destructuring is used to unpack values from arrays or objects into distinct variables, while the spread operator is used to expand elements of an iterable or properties of an object.
  • Spread operator is mainly used to create shallow copies of arrays or objects, merge arrays or objects, expand array or objects with new objects, merge arrays or objects, expand array or objects with new properties on top of existing, and pass elements as individual arguments to functions .

Rest Operators

  • The Rest Operator (...) is used to collect multiple elements into a single array or object.
  • It is useful for handling function parameters, array destructuring, and object destructuring.
  • Rest parameters must be the last parameter in a function definition.

Short Circuiting (&& and ||)

  • Short-circuiting is a programming technique where the evaluation of a logical expression stops as soon as the outcome is determined.
  • In JavaScript, the logical operators AND (&&) and OR (||) exhibit short-circuiting behavior.
  • With the OR operator (||), if the first operand is truthy, the second operand is not evaluated because the overall expression will be true. It will return the first truthy value.
  • With the AND operator (&&), if the first operand is falsy, the second operand is not evaluated because the overall expression will be false. It will return the first falsy value.

Nullish Coalescing Operator (??)

  • The Nullish Coalescing Operator (??) is a logical operator that returns the right-hand operand when the left-hand operand is null or undefined.
  • It is useful for providing default values when dealing with potentially null or undefined variables.
  • Unlike the OR operator (||), which considers all falsy values (like 0, '', false) as triggers to return the right-hand operand, the Nullish Coalescing Operator only considers null and undefined.

Logical Assignment Operatorsin ES 2021

  • Logical Assignment Operators are a combination of logical operators (&&, ||, ??) with assignment (=) to provide a concise way to assign values based on certain conditions.
  • The three logical assignment operators are:
    • Logical OR Assignment (||=)
    • Logical AND Assignment (&&=)
    • Nullish Coalescing Assignment (??=)
  • These operators help simplify code by reducing redundancy when assigning values based on conditions.

Looping Arrays for-of loop

  • The for-of loop is a modern way to iterate over iterable objects like arrays, strings, maps, and sets in JavaScript.
  • It provides a simpler syntax compared to traditional loops like for and while, making the code more readable and concise.
  • The for-of loop automatically handles the iteration process, allowing developers to focus on the logic inside the loop.

Enhanced Object Literals

  • Enhanced Object Literals is a feature in JavaScript that allows for a more concise and expressive syntax when defining objects.
  • It includes shorthand property names, method definitions, and computed property names.
  • This feature improves code readability and reduces redundancy when creating objects.

Optional Chaining (?.)

  • Optional Chaining (?.) is a feature in JavaScript that allows safe access to deeply nested object properties without having to check for the existence of each property in the chain.
  • It helps prevent runtime errors that occur when trying to access properties of undefined or null values.
  • If any part of the chain is null or undefined, the entire expression short-circuits and returns undefined instead of throwing an error.

Looping Object Properties

  • Looping Object Properties involves iterating over the keys, values, or entries of an object using methods like Object.keys(), Object.values(), and Object.entries().
  • This allows developers to access and manipulate object properties efficiently.
  • It is useful for tasks such as data processing, transformation, and analysis.

Sets

  • A Set is a built-in JavaScript object that allows you to store unique values of any type, whether primitive values or object references.
  • Sets automatically handle duplicate values, ensuring that each value is stored only once.
  • They provide useful methods for adding, deleting, and checking for the existence of values, as well as properties to get the size of the Set.
  • Real time scenario when we use set: Storing unique user IDs in a web application to prevent duplicate entries.

Sets Methods till now

  • add(value): Adds a new element with the given value to the Set.
  • delete(value): Removes the specified element from the Set.
  • has(value): Returns a boolean indicating whether the Set contains the specified value.
  • clear(): Removes all elements from the Set.
  • size: A property that returns the number of elements in the Set.
  • Intersection: Returns a new Set containing elements that are present in both Sets.
  • Union: Returns a new Set containing all unique elements from both Sets.
  • Difference: Returns a new Set containing elements that are in the first Set but not in the second Set.
  • Symmetric Difference: Returns a new Set containing elements that are in either of the Sets but not in both.
  • isDisjoint: Returns a boolean indicating whether two Sets have no elements in common.

Maps

  • A Map is a built-in JavaScript object that allows you to store key-value pairs, where both keys and values can be of any type (primitive values or object references).
  • Maps maintain the order of insertion, meaning that when you iterate over a Map, the entries will be returned in the order they were added.
  • They provide useful methods for adding, deleting, and retrieving values based on their keys, as well as properties to get the size of the Map.
  • Real time scenario when we use map: Storing and managing user session data in a web application.

Maps Methods till now

  • set(key, value): Adds a new key-value pair to the Map.
  • get(key): Retrieves the value associated with the specified key.
  • has(key): Returns a boolean indicating whether the Map contains the specified key.
  • delete(key): Removes the specified key-value pair from the Map.
  • clear(): Removes all key-value pairs from the Map.
  • size: A property that returns the number of key-value pairs in the Map.

When to Use Arrays vs Sets and Objects vs Maps in real time scenario

  • Use Arrays when you need an ordered collection of items that may contain duplicates, such as a list of tasks or a collection of user comments.
  • Use Sets when you need to store unique values and want to prevent duplicates, such as a collection of unique user IDs or tags.
  • Use Objects when you need to store key-value pairs with string keys, such as user profiles or configuration settings.
  • Use Maps when you need to store key-value pairs with keys of any type (not just strings) and want to maintain the order of insertion, such as caching data with complex keys or storing metadata.

Working with strings

  • Strings in JavaScript are sequences of characters used to represent text.
  • Strings are immutable, meaning that once created, their values cannot be changed. Any operation that modifies a string will create a new string instead.
  • How methods are working in strings: JS automatically converts String into Object when methods are called. This is called "boxing".
  • Chaining methods allows you to perform multiple operations on a string in a single line of code.

String Methods used in this course

  • length: returns the length of the string
  • indexOf, lastIndexOf: returns the index of a specified value in a string
  • slice: extracts a section of a string and returns it as a new string
  • toLowerCase, toUpperCase: converts the string to lowercase or uppercase
  • trim: removes whitespace from both ends of a string
  • replace, replaceAll: replaces occurrences of a substring with a new substring
  • includes, startsWith, endsWith: checks if a string contains, starts with, or ends with a specified substring
  • split, join: splits a string into an array or joins an array into a string
  • padStart, padEnd: pads a string with another string until it reaches a specified length
  • repeat: repeats a string a specified number of times
