A Closer Look at Functions

Function default parameters

  • Reason for default parameters: To provide default values for function parameters when no arguments are passed or when undefined is passed.
  • Helps avoid errors and ensures functions behave predictably.
  • How to write default parameters in es6: Use the syntax function(param = defaultValue) { ... }

Passing Arguments: Values vs. Reference

  • Primitive data types (e.g., numbers, strings, booleans) are passed by value.
  • Objects (including arrays and functions) are passed by reference.
  • Changes made to primitive parameters inside a function do not affect the original value outside the function.
  • Changes made to object parameters inside a function can affect the original object outside the function.
  • Note: Javascript always pass by value not doing pass by reference like c, c++

First-Class and Higher-Order Functions

  • First-Class Functions: Functions are treated as first-class citizens in JavaScript, meaning they can be assigned to variables, passed as arguments to other functions, and returned from other functions.
  • Higher-Order Functions: Functions that can take other functions as arguments or return functions as their result.
  • Examples of higher-order functions include map, filter, and reduce.

Functions accepting callback functions

  • A callback function is a function passed into another function as an argument to be executed later.
  • Callbacks are commonly used for asynchronous operations, event handling, and functional programming techniques.
  • Example: In array methods like map, filter, and forEach, callback functions are used to process each element of the array.
  • Abstraction: Callbacks help abstract away complex logic, making code more modular and easier to maintain.

Functions returning functions

  • Functions can return other functions, allowing for the creation of higher-order functions and function factories.
  • This technique is useful for creating specialized functions based on certain parameters or conditions.
  • Example: A function that generates greeting functions based on a given greeting message.

Call and apply methods

  • Both call and apply are methods that allow you to invoke a function with a specified this context.
  • The main difference is in how arguments are passed: call accepts a list of arguments, while apply accepts an array of arguments.
  • Example: 
    function greet(greeting, punctuation) {
  console.log(greeting + ', ' + this.name + punctuation);
} 
const person = { name: 'Alice' };
greet.call(person, 'Hello', '!'); // Using call
greet.apply(person, ['Hi', '!!']); // Using apply

Bind Method

  • The bind method creates a new function that, when called, has its this keyword set to the provided value.
  • It allows you to create a copy of a function with a specific this context and optional preset arguments.
  • Difference between call/apply and bind: call and apply invoke the function immediately, while bind returns a new function with a bound this context.
  • Real time scenario: Binding event handlers to maintain the correct this context.
  • Example: 
    const person = { name: 'Bob' };
function greet(greeting) {
  console.log(greeting + ', ' + this.name);
}
const greetBob = greet.bind(person);
greetBob('Hello'); // Output: Hello, Bob

Immediately Invoked Function Expressions (IIFE)

  • An IIFE is a function that is defined and immediately executed after its creation.
  • It is commonly used to create a new scope and avoid polluting the global namespace.
  • Syntax: (function() { ... })(); or (() => { ... })();
  • Example: 
    (function() {
  const message = 'Hello, World!';
  console.log(message);
})();

Closures

  • Closure is closed over variables environment in which functions was created even after its execution context is gone.
  • A closure is a function that retains access to its lexical scope, even when the function is executed outside that scope.
  • Closures are created whenever a function is defined inside another function.
  • They are useful for data privacy, creating function factories, and maintaining state in asynchronous code.
  • Real Time Scenario for Closures: Maintaining state in asynchronous code, Timers(setTimeout, setInterval)
  • Example: 
    function outer() {
  let count = 0;
  return function inner() {
    count++;
    console.log(count);
  };
} 
const counter = outer();
counter(); // Output: 1
counter(); // Output: 2
