JavaScript Numbers, dates, internationalisation and timers

Ways to convert and check Numbers

  • Number() - to convert strings and booleans to numbers
  • parseInt() - to convert strings to integers
  • parseFloat() - to convert strings to floating point numbers
  • isNaN() - to check if a value is NaN
  • isFinite() - to check if a value is a finite number
  • isInteger() - to check if a value is an integer
  • Math.sqrt(), Math.max(), Math.min(), Math.PI - various math functions and constants
  • +(string) - to convert a string to a number


Mathematical Operations

  • Math.floor() - to round down to the nearest integer
  • Math.ceil() - to round up to the nearest integer
  • Math.round() - to round to the nearest integer
  • Math.trunc() - to truncate a number (remove decimal part)


Rounding Decimals & Integers

  • toFixed() - to format a number to a fixed number of decimal places
  • toPrecision() - to format a number to a fixed number of significant digits
  • round() - to round a number to the nearest integer
  • ceil() - to round a number up to the nearest integer
  • floor() - to round a number down to the nearest integer


Reminders

  • % - to get the remainder of a division
  • ** - to perform exponentiation (power)


Numeric Separators

  • 1234567890 - to separate digits in large numbers
  • 1_234_567_890 - to separate digits in large numbers (ES2021)
  • Advantages: Improved readability and maintainability of large numbers.
  • How it works: The underscore is ignored by JavaScript and only serves as a visual separator.


Big Int

  • BigInt is a built-in object in JavaScript that provides a way to represent integers with arbitrary precision.
  • Advantages: Can handle very large integers that exceed the range of regular numbers.
  • Drawbacks: BigInts cannot be used with regular numbers in arithmetic operations without explicit conversion. It cannot used in logical operations.
  • BigInt() - to create a BigInt value
  • 123n - to create a BigInt literal
  • BigInt(123) - to convert a number to a BigInt
  • 123n + 456n - to perform arithmetic operations with BigInts


Dates and Times

  • A date is a data type that represents a specific point in time, including the year, month, day, hour, minute, second, and millisecond.
  • A time is a data type that represents a specific point in time, including the hour, minute, second, and millisecond.
  • new Date() - to create a new date object with the current date and time
  • new Date(dateString) - to create a new date object from a date string
  • new Date(year, monthIndex, day, hours, minutes, seconds, milliseconds) - to create a new date object with specific date and time
  • Date.now() - to get the current timestamp in milliseconds since January 1, 1970
  • date.getFullYear() - to get the year of a date object
  • date.getMonth() - to get the month of a date object (0-11)
  • date.getDate() - to get the day of the month of a date object (1-31)
  • date.getHours() - to get the hours of a date object (0-23)
  • date.getMinutes() - to get the minutes of a date object (0-59)
  • date.getSeconds() - to get the seconds of a date object (0-59)
  • date.toISOString() - to convert a date object to an ISO string (YYYY-MM-DDTHH:mm:ss.sssZ)
  • date.toLocaleDateString(locale, options) - to format a date object according to a specific locale and options (e.g., long date formata)
