Arrays Methods Practice

Slice Method

  • Definition: The slice() method returns a shallow copy of a portion of an array into a new array object selected from start to end (end not included) where start and end represent the index of items in that array. The original array will not be modified.
  • Syntax: array.slice(start, end)
  • Mutate origin Array: No
  • Alternate option: [...array].slice(start, end)
  • When to use slice: To create a new array by extracting a portion of an existing array without modifying the original array.
  • Disadvantages: Does not modify the original array, so additional memory is used for the new array

Splice Method

  • Definition: The splice() method changes the contents of an array by removing or replacing existing elements and/or adding new elements in place.
  • Syntax: array.splice(start, deleteCount, item1, item2, ...)
  • Mutate origin Array: Yes
  • Alternate option: N/A
  • When to use splice: To modify an existing array by adding, removing, or replacing elements directly within that array.
  • Disadvantages: Mutates the original array, which can lead to unexpected side effects

Reverse Method

  • Definition: The reverse() method reverses an array in place. The first array element becomes the last, and the last array element becomes the first.
  • Syntax: array.reverse()
  • Mutate origin Array: Yes
  • Alternate option: [...array].reverse()
  • When to use reverse: To reverse the order of elements in an array in place.
  • Disadvantages: Mutates the original array, which can lead to unexpected side effects

Concat Method

  • Definition: The concat() method is used to merge two or more arrays. This method does not change the existing arrays, but instead returns a new array.
  • Syntax: array1.concat(array2, array3, ...)
  • Mutate origin Array: No
  • Alternate option: [...array1, ...array2]
  • When to use concat: To merge two or more arrays into a new array without modifying the original arrays.
  • Disadvantages: Does not modify the original arrays, so additional memory is used for the new array

Join Method

  • Definition: The join() method creates and returns a new string by concatenating all of the elements in an array (or an array-like object), separated by commas or a specified separator string.
  • Syntax: array.join(separator)
  • Mutate origin Array: No
  • Alternate option: N/A
  • When to use join: To create a string from all elements in an array, separated by a specified separator.
  • Disadvantages: Does not modify the original array, so additional memory is used for the new string

At Method

  • Definition: The at() method takes an integer value and returns the item at that index, allowing for positive and negative integers. Negative integers count back from the last item in the array.
  • Syntax: array.at(index)
  • Mutate origin Array: No
  • Alternate option: array[index]
  • When to use at: To access an element at a specific index, including negative indices for counting from the end.
  • Disadvantages: Does not modify the original array, so additional memory is used for accessing elements

ForEach Method

  • Definition: The forEach() method executes a provided function once for each array element.
  • Syntax: array.forEach(callback(currentValue, index, array))
  • Mutate origin Array: No
  • Alternate option: for loop
  • When to use forEach: To perform an action for each element in an array without creating a new array(create new property inside exisitng object).
  • forEach with maps and sets: Use forEach to iterate over Map and Set collections, with callback parameters adapted for each.
  • Syntax: map.forEach(callback(value, key, map)) and set.forEach(callback(value, value2, set))
  • Disadvantages: Cannot use break or continue statements to control the loop; can only use return to exit the current iteration.

Map Method

  • Definition: The map() method creates a new array populated with the results of calling a provided function on every element in the calling array.
  • Syntax: array.map(callback(currentValue, index, array))
  • Mutate origin Array: No
  • Alternate option: for loop to push values into a new array
  • When to use map: To transform each element in an array and create a new array with the transformed elements.
  • Difference between Map and forEach method: map returns a new array with transformed elements, forEach simply executes a function on each element without returning a new array.
  • Side Effects: map should be used when you want to transform data without side effects; forEach is typically used for side effects like logging or updating external variables.

Filter Method

  • Definition: The filter() method creates a new array with all elements that pass the test implemented by the provided function.
  • Syntax: array.filter(callback(currentValue, index, array))
  • Mutate origin Array: No
  • Alternate option: for loop to push values into a new array
  • When to use filter: To select a subset of elements from an array based on a condition.

Reduce Method

  • Definition: The reduce() method executes a reducer function (that you provide) on each element of the array, resulting in a single output value.
  • Syntax: array.reduce(callback(accumulator, currentValue, index, array), initialValue) initialValue = 0 / arr[0]., then currentValue=arr[1]
  • Mutate origin Array: No
  • Alternate option: for loop to accumulate a single value
  • When to use reduce: To boil down an array to a single value, such as a sum, product, or concatenated string.

Array of Chain Methods

  • Definition: Chaining array methods involves calling multiple methods in a single line, where the output of one method serves as the input for the next.
  • Syntax: array.method1().method2().method3()... (e.g., array.filter().map().reduce())
  • Mutate origin Array: Depends on the methods used in the chain
  • Alternate option: Separate method calls with intermediate variables
  • When to use chain methods: To perform multiple transformations or computations on an array in a concise and readable manner.
  • Disadvantages: Can be harder to debug and may impact performance if overused

Find Method

  • Definition: The find() method returns the value of the first element in the provided array that satisfies the provided testing function. Otherwise, undefined is returned.
  • Syntax: array.find(callback(currentValue, index, array))
  • Mutate origin Array: No
  • Alternate option: for loop with conditional return
  • When to use find: To locate a single element in an array that meets a specific condition(Useful for find objects from array of objects).
  • Disadvantages: Only returns the first matching element; subsequent matches are ignored

FindIndex Method

  • Definition: The findIndex() method returns the index of the first element in the provided array that satisfies the provided testing function. Otherwise, -1 is returned.
  • Syntax: array.findIndex(callback(currentValue, index, array))
  • Mutate origin Array: No
  • Alternate option: for loop with conditional return and index tracking
  • When to use findIndex: To locate the index of a single element in an array that meets a specific condition.
  • Difference between indexOf and findIndex: indexOf returns the index of the first element that matches a value, while findIndex returns the index of the first element that satisfies a condition.
  • Disadvantages: Only returns the index of the first matching element; subsequent matches are ignored

FindLast & FindLastIndex Methods

  • Definition: The findLast() method returns the value of the last element in the provided array that satisfies the provided testing function. The findLastIndex() method returns the index of the last element that satisfies the provided testing function.
  • Syntax: array.findLast(callback(currentValue, index, array)) and array.findLastIndex(callback(currentValue, index, array))
  • Mutate origin Array: No
  • Alternate option: for loop iterating from end to start with conditional return
  • When to use findLast & findLastIndex: To locate the last element or its index in an array that meets a specific condition.
  • Disadvantages: Only returns the last matching element or its index; previous matches are ignored

Some

  • Definition: The some() method tests whether at least one element in the array passes the provided testing function.
  • Syntax: array.some(callback(currentValue, index, array))
  • Mutate origin Array: No
  • Alternate option: for loop with conditional return
  • When to use some: To check if at least one element in an array meets a specific condition.
  • Difference between some and includes: some() tests a condition for each element, while includes() checks if a specific value exists in the array.
  • Disadvantages: None significant( None Significant means no significant disadvantages)

Every Method

  • Definition: The every() method tests whether all elements in the array pass the provided testing function.
  • Syntax: array.every(callback(currentValue, index, array))
  • Mutate origin Array: No
  • Alternate option: for loop with conditional return
  • When to use every: To check if all elements in an array meet a specific condition.
  • Disadvantages: None significant

Flat & FlatMap Methods

  • Definition: The flat() method creates a new array with all sub-array elements concatenated into it recursively up to the specified depth. The flatMap() method first maps each element using a mapping function, then flattens the result into a new array.
  • Syntax: array.flat(depth) and array.flatMap(callback(currentValue, index, array))
  • Mutate origin Array: No
  • Alternate option: for loop with recursion for flattening
  • When to use flat & flatMap: To flatten nested arrays or to map and flatten in a single step.
  • Disadvantages: flatMap only flattens one level deep; for deeper flattening, use flat separately

Sort Method

  • Definition: The sort() method sorts the elements of an array in place and returns the sorted array.
  • Syntax: array.sort(compareFunction)
  • SortNum: Sort numbers in ascending order definition- If result is negative, a is before b. If result is positive, b is before a.
  • Mutate origin Array: Yes
  • Alternate option: [...array].sort(compareFunction)
  • When to use sort: To arrange the elements of an array in a specific order (ascending or descending).
  • Disadvantages: Mutates the original array, which can lead to unexpected side effects

Group By Arrays

  • Definition: groupBy Array Methods is new feature introduced in ES2024
  • Syntax: Object.groupBy(array, callback(currentValue, index, array))
  • Mutate origin Array: No
  • Alternate option: N/A
  • When to use groupBy: To group elements of an array based on a specific criterion.
  • Disadvantages: None significant

Ways to Create Arrays

  • Array Literal: const arr = [1, 2, 3];
  • Array Constructor: const arr = new Array(1, 2, 3);
  • Array(3): const arr = Array(3); => arr[empty,empty,empty]
  • Array fill: const arr = Array(3).fill(0); // [0, 0, 0]
  • Array.from(): const arr = Array.from('123'); // ['1', '2', '3']. Definition: Creates an array from an iterable object.

Non Destructive Array Alternatives Methods: toReversed(), toSpliced(), toSorted(), with()

  • Definition: These methods create a new array with the desired changes without modifying the original array.
  • Syntax: array.toReversed(), array.toSpliced(), array.toSorted(), array.with(index, value)
  • Array with mainly used to change array value based on index i.e: arr[0]='Hi')
  • Mutate origin Array: No
  • Alternate option: N/A
  • When to use Non Destructive Array Alternatives Methods: When you want to make changes to an array without affecting the original array.
  • Disadvantages: None significant

Summary

  • Array methods are powerful tools for manipulating and transforming arrays in JavaScript.
  • Understanding when and how to use each method is crucial for writing efficient and readable code.
  • Always consider whether a method mutates the original array or returns a new one, as this can impact your program's behavior.
  • Practice using these methods in various scenarios to become more comfortable with their applications.
  • Refer to the official documentation for more details and examples on each method.
  • Happy coding and exploring the world of arrays in JavaScript!
