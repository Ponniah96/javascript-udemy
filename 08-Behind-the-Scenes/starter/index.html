Hoisting and TDZ

  • Hoisting: The process by which variable and function declarations are moved to the top of their containing scope during the compile phase
  • Hoisting with var, let, const: Variables declared with var are hoisted and initialized with undefined, while let and const are hoisted but not initialized, leading to the Temporal Dead Zone (TDZ)
  • Temporal Dead Zone (TDZ): The time between the entering of the scope and the variable declaration where the variable cannot be accessed
  • Hoisting with Functions: Function declarations are hoisted and can be called before they are defined, while function expressions and arrow functions behave like variables in terms of hoisting

this keyword

  • The this keyword in JavaScript refers to the object that is executing the current function
  • In the global context, this refers to the global object (window in browsers)
  • In a regular function, this refers to the object that called the function
  • In an arrow function, this is lexically bound and refers to the this value of the enclosing scope. Not suitable to call this and arguments keywords (but it will be suitable only inside object methods)
  • In event handlers, this refers to the DOM element that received the event

Memory Management

  • JavaScript uses automatic memory management through a process called garbage collection
  • Memory allocation occurs when variables, objects, or data structures are created
  • Garbage collection identifies and frees up memory that is no longer reachable or needed by the program
  • JavaScript primarily uses the mark-and-sweep algorithm for garbage collection
  • Developers can help optimize memory usage by avoiding memory leaks, managing references, and using efficient data structures

Object references

  • In JavaScript, objects are stored and assigned by reference, meaning that when you assign an object to a variable or pass it to a function, you are working with a reference to the original object rather than a copy of it
  • When you create an object and assign it to a variable, the variable holds a reference (or pointer) to the memory location where the object is stored
  • Normal Copy: 
    const object2 = object1
  • Shallow Copy(Spread operator): Creates a new object with the same top-level properties as the original object. However, nested objects or arrays are still referenced, meaning changes to nested structures in the arrays are still referenced, meaning changes to nested structures in the copied object will affect the original object and vice versa. 
    const object2 = Object.assign({}, object1);
  • Deep Copy(structuredClone): Creates a new object that is a complete copy of the original object, including all nested objects and arrays. Changes made to the copied object do not affect the original object and vice versa. 
    const object2 = structuredClone(object1);
